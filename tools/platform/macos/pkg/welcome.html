This installs KM Video Tools: two programs for getting karaoke video songs onto disk, in the shape a karaoke package wants them.

  • KM Video Downloader — the window. Set a folder once, paste the links or pick a file of them, press Fetch, and watch it happen. It goes into /Applications.
  • km-video-fetch — the same fetch on the command line. It goes into /usr/local/km-video-tools, with a symlink in /usr/local/bin, which is already on your PATH. Nothing is added to a .zshrc.

You can install either one on its own on the next page.

Neither of them does the downloading. That is yt-dlp, which this installer does not include and does not fetch — these programs are the selector, the tags and the check around it. Install it separately from https://github.com/yt-dlp/yt-dlp, or with Homebrew: brew install yt-dlp. Add ffmpeg too if you want the check on whether what arrived is actually playable.

This package is not signed with a Developer ID. If macOS refused to open it on a double-click, Control-click the .pkg and choose Open, or allow it under System Settings → Privacy & Security.

It asks for your administrator password once, for those two directories, and reaches the network at no point.
