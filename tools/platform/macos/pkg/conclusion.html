Installed.

  • KM Video Downloader is in /Applications. Open it from Launchpad or the Applications folder.
  • km-video-fetch can be typed in any new Terminal window. One that was already open will not have found it yet.

Double-clicking a .kmvf list of links opens KM Video Downloader with that list filled in and the folder set to the one the list is in. Nothing is fetched until you press Fetch, and a second list opened while the window is up goes to that window rather than starting a second copy.

Before the first download, install yt-dlp if you have not already — brew install yt-dlp, or from https://github.com/yt-dlp/yt-dlp. Both programs print the version they found and warn when it is too old. An out-of-date yt-dlp fails in ways that look like a broken network.

Where things are, if you want them gone later:

  • The application: /Applications/KM Video Downloader.app — drag it to the Trash. That takes the .kmvf association with it; nothing else has to be undone.
  • The command line: /usr/local/km-video-tools and the symlink /usr/local/bin/km-video-fetch — deleting those needs the same administrator password the install asked for.
  • Your settings: ~/Library/Application Support/km-video-downloader.

The videos you download are never touched by any of that, wherever you chose to put them.
